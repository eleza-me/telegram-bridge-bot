# ربات پل تلگرام ← الزا

هر چیزی که در تلگرام برای این ربات **بفرستی یا فوروارد کنی**، با **حساب خودت** در الزا منتشر می‌شود:

- **📝 الی**: به‌صورت پست
- **💾 ذخیره**: در «پیام‌های ذخیره‌شده»ی خودت در الزا
- **📝+💾 هر دو**

بعد از هر پیام، ربات با دکمه می‌پرسد کجا بفرستد. با `/mode` می‌شود یک مقصد ثابت گذاشت تا دیگر نپرسد.

## چطور کار می‌کند

ربات مثل یک **دستگاه** (مثل یک نسخهٔ دسکتاپ) وارد حساب الزای تو می‌شود: شماره را می‌دهی، الزا کد پیامک می‌کند و کد را به ربات می‌دهی (و اگر تأیید دومرحله‌ای داری، رمز را هم). از آن به بعد ربات توکنش را خودش تمدید می‌کند.

- در الزا، بخش **دستگاه‌ها**، با نام «Telegram bridge» دیده می‌شود و هر وقت بخواهی از همان‌جا قطعش می‌کنی.
- فقط از API عمومی الزا استفاده می‌کند و به هیچ تغییری در بک‌اند نیاز ندارد.
- فقط به **آیدی تلگرام خودت** (`TELEGRAM_OWNER_ID`) جواب می‌دهد و بقیه را نادیده می‌گیرد.

## امنیت

- ربات یک نشست کامل حساب تو را نگه می‌دارد، پس به اندازهٔ یک گوشیِ واردشده حساس است.
- نشست در فایل `/data/state.enc` نگه داشته می‌شود و با `BRIDGE_SECRET_KEY` (AES-256-GCM) رمزنگاری شده است. اگر کلید را گم کنی، فقط باید دوباره `/login` کنی.
- توکن تمدید (refresh) به یک کلید Ed25519 گره خورده که فقط داخل همان فایل است. یعنی اگر فقط توکن دزدیده شود، به‌تنهایی کار نمی‌کند.
- ربات کد پیامکی و رمز دومرحله‌ای را بلافاصله بعد از خواندن از چت تلگرام پاک می‌کند.
- **محدودیت:** پیام کد و رمز از سرورهای تلگرام رد می‌شود. اگر این برایت قابل‌قبول نیست، از این ربات استفاده نکن.
- ورود حدود **۶۰ روز** اعتبار دارد (`auth.refresh_token_ttl`). چند روز قبل از تمام‌شدنش ربات خبر می‌دهد که دوباره `/login` کنی.

## راه‌اندازی

**۱. ساخت ربات تلگرام:** در [@BotFather](https://t.me/BotFather) دستور `/newbot` را بزن و توکن را بردار.

**۲. آیدی عددی خودت در تلگرام:** مثلاً از [@userinfobot](https://t.me/userinfobot).

**۳. کلید رمزنگاری:**
```bash
openssl rand -base64 32
```

**۴. فایل `.env`:**
```bash
cp .env.example .env
# TELEGRAM_BOT_TOKEN, TELEGRAM_OWNER_ID و BRIDGE_SECRET_KEY را پر کن
```

**۵. اجرا:**
```bash
docker compose up -d --build
docker compose logs -f tgbridge
```
یا بدون Docker (Go 1.24 به بالا):
```bash
set -a; . ./.env; set +a
BRIDGE_DATA_DIR=./data go run ./cmd/tgbridge
```

**۶. ورود:** در تلگرام به ربات `/login` بزن و مراحل را برو.

> **کجا اجرا شود؟** سرور باید هم به `api.telegram.org` دسترسی داشته باشد و هم به `api.eleza.me`. تلگرام در ایران فیلتر است، پس معمولاً سروری بیرون از ایران لازم است (یا یک پروکسی: `HTTPS_PROXY` رعایت می‌شود).

## دستورها

| دستور | کار |
|---|---|
| `/login` | ورود به الزا (شماره، کد پیامکی، رمز دومرحله‌ای) |
| `/mode` | مقصد پیش‌فرض: هر بار بپرس، الی، ذخیره، یا هر دو |
| `/status` | به کدام حساب وصل است و تا کی |
| `/logout` | خروج (نشست در سرور الزا هم بسته می‌شود) |
| `/cancel` | لغو ورود در حال انجام |

## چه چیزهایی منتقل می‌شوند

| تلگرام | الی | پیام‌های ذخیره‌شده |
|---|---|---|
| متن | پست متنی. اگر از ۵۰۰ کاراکتر بلندتر باشد، **رشته (thread)** تا ۲۵ بخش، و بقیه به‌صورت پاسخ زیر پست اول | با فرمت (بولد، ایتالیک، لینک، کد، اسپویلر…)؛ متن بلند به چند پیام شکسته می‌شود |
| لینک پشت متن | آدرسش در پرانتز بعد از متن می‌آید | لینک می‌ماند |
| عکس، ویدیو | پست مدیا (آلبوم تا ۸ تا؛ بیشترش پست‌های بعدی) | عکس، ویدیو (آلبوم تا ۱۰ تا) |
| آلبوم | یک پست | یک آلبوم |
| گیف | ویدیو | گیف |
| ویدیو مسیج | پست ویدیو مسیج | ویدیو مسیج |
| ویس، آهنگ | پست صوتی (تا ۱۰ دقیقه) | ویس، آهنگ |
| فایل | فقط اگر عکس یا ویدیو باشد | فایل |
| نظرسنجی | نظرسنجی الی (تا ۴ گزینه، مدت `BRIDGE_POLL_DURATION`) | به‌صورت متن |
| موقعیت | لینک نقشه | موقعیت مکانی |
| مخاطب | متن | متن |
| استیکر | — | — |

پیام‌های فورواردی یک خط «↪️ از …» می‌گیرند که اگر منبع عمومی باشد لینک پیام اصلی را هم دارد (`BRIDGE_FORWARD_SOURCE=false` این خط را حذف می‌کند).

پیام‌ها در «پیام‌های ذخیره‌شده» بی‌صدا فرستاده می‌شوند (بدون نوتیفیکیشن روی گوشی خودت).

## اگر ارسال خطا بدهد

زیر پیام وضعیت دکمهٔ **🔁 دوباره** می‌آید. هر مورد یک کلید ثابت دارد (`Idempotency-Key` برای پست و `client_message_id` برای پیام)، پس تلاش دوباره هیچ‌وقت چیزی را **دو بار** منتشر نمی‌کند.

## فایل‌های بزرگ‌تر از ۲۰ مگابایت

API عمومی تلگرام فایل‌های بزرگ‌تر از ۲۰ مگابایت را به ربات نمی‌دهد. برای این فایل‌ها (تا ۲ گیگ) باید یک [سرور Bot API محلی](https://github.com/tdlib/telegram-bot-api) کنار ربات اجرا کنی:

1. `TELEGRAM_API_ID` و `TELEGRAM_API_HASH` را از [my.telegram.org](https://my.telegram.org) بگیر و در `.env` بگذار.
2. ربات را یک بار از سرور عمومی خارج کن:
   ```bash
   curl https://api.telegram.org/bot$TELEGRAM_BOT_TOKEN/logOut
   ```
3. در `.env` این دو را بگذار:
   ```
   TELEGRAM_API_URL=http://botapi:8081
   TELEGRAM_LOCAL_MODE=true
   ```
4. در `docker-compose.yml` خط volume مربوط به `botapi-data` را برای `tgbridge` از حالت کامنت دربیاور.
5. اجرا کن:
   ```bash
   docker compose --profile bigfiles up -d
   ```

سقف خود الزا هم اعمال می‌شود: عکس ۲۰ مگابایت، ویدیو و آهنگ ۲۵۶ مگابایت (تنظیمات `media.*` سرور).

## سقف‌ها

ربات سقف‌های پیش‌فرض سرور را می‌شناسد:

- الی: ۵۰۰ کاراکتر، رشته تا ۲۵ بخش، آلبوم ۸ تایی
- چت: پیام ۴۰۹۶ کاراکتر، کپشن ۱۰۲۴ کاراکتر، آلبوم ۱۰ تایی

اگر این سقف‌ها در پنل ادمین کمتر شده باشند، با `ELI_*` و `CHAT_*` در `.env` کمشان کن. سقف تعداد پست در ساعت هم اعمال می‌شود (پیش‌فرض ۳۰ پست در ساعت): وقتی پر شود، ربات صبر می‌کند و دوباره تلاش می‌کند.
